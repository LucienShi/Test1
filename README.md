# 视频自动学习脚本（含UI）

## 功能
- 从当前已打开的目录页开始执行。
- 逐条查找“学习中”或“开始学习”按钮并打开视频。
- 自动点击播放、强制静音、读取剩余时间。
- 读取失败时使用 40 分钟兜底计时。
- 看完后关闭视频页，返回目录页并刷新。
- 当前页无待看视频时滚动到底部后翻页，直到第5页结束。
- 提供简单 UI（开始/停止 + 实时状态与日志）。

## 环境准备
1. Python 3.10+
2. 安装依赖：
   ```bash
   pip install playwright
   playwright install chromium
   ```
3. 以远程调试模式启动 Edge（示例）：
   ```bash
   msedge --remote-debugging-port=9222
   ```
4. 手动登录并打开课程目录页（`/classBase/classStudy`）。

## 运行
```bash
python auto_video_ui.py
```

## 注意
- 脚本通过 CDP 连接 `http://127.0.0.1:9222`。
- UI 可保持在前台，自动化会在关键步骤将浏览器标签页切到前台再操作。
- 页面结构若变动（按钮文案/分页结构）需要同步调整选择器。
